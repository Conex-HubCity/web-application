# Conex — Aperçu de développement

**Ne pas publier ni mettre en ligne.** Version privée destinée à la présentation et aux tests.

Ouvrir `index.html` dans un navigateur récent. Aucun serveur, installation, compte ou accès réseau n’est nécessaire. Conserver les fichiers CSS, JS et le dossier `assets` à côté du HTML.

L’accueil reprend le hero, les photos, les deux parcours, les engagements, la FAQ et le splash CNX animé suivi de « A solution by HubCity ». Un modal rappelle le caractère privé de cet aperçu après l’introduction. Le bouton du pied de page permet de rejouer le splash. L’animation respecte la préférence de mouvement réduit.

Cette version ne contient ni connexion, ni inscription, ni panel, ni accès à la base de données. Les boutons présentent les parcours. Aucun fichier utilisateur, identifiant ou document confidentiel n’est inclus.
